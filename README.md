
# About
This project is designed to clean and proces the relevant data to later be using in making a Power BI report.

## Setup
1) Ensure that python is installed on your machine.
2) Create a virtual environment for the project by running `python -m venv .venv`
3) Enter the virtual environment by running `source .venv/bin/activate` for linux or `.\.venv\Scripts\Activate.ps1` for windows (See https://docs.python.org/3/library/venv.html for more information)
4) Install the relevant libraries for the project by running `pip install -r requirements.txt`

## Running
1) Ensure you have entered the virtual environment by running `source .venv/bin/activate` for linux or `.\.venv\Scripts\Activate.ps1` for windows (See https://docs.python.org/3/library/venv.html for more information)
2) Run the program by running `python main.py`

Note that the program does require an AI to run, see AI requirements.

## Usage
To run the program you need at minimum the following complete datasets:
1) challenges.csv
2) sponsors.csv
3) users.csv
Once run it will process the data and generate the new data files:
1) ethnicity_join_table.csv
2) ethnicity_table.csv
3) postcode_table.csv
4) processed_challenges.csv
5) processed_sponsors.csv
6) reward_table.csv
7) submissions_join_table.csv
Once run it will store in memory the following:
1) ethnicity_mapping.json
2) gender_mapping.json
3) postcode_coordinates.json
The first two of these are worth checking for mistakes as these are what the AI is being run through.
Postcode Coordinates should be included as it will very rarely need to be updated see the Updating Postcode Table section for more information on that.
These are stored to increase repeatability, reliablity (as the first two go through the AI which has no memory of previous runs) and speed up future runs.

## AI requirements.
So far only local models are supported using ollama.
See https://ollama.com/download/windows for how to install ollama.
Once installed the following models need to be installed:
- llama3.5:8b

## The Memory folder
The memory folder contains memory from previous runs regarding postcodes, gender mappings and ethnicity.
You can edit the json files if you want to fine tune the mappings generated by the AI.

## Updating Postcode Table
This will probably never need to be done as postcodes don't change that much.
1) Get the latest data from [https://github.com/s01ipsist/open_nz_postcodes/releases] and [https://datafinder.stats.govt.nz/layer/120945-regional-council-2025-clipped/] (To update the regional dataset you will need to find other data).
2) Put the data in the data folder
3) Delete the postcode_coordinates.json file in memory
4) Run the program
The table will now be updated.
